Java/Spring Boot 기반 백엔드 메인 개발자로서 시스템 초기 아키텍처 설계부터 Docker · GitHub Actions를 활용한 CI/CD 구축 및 배포까지 전 과정을 주도해온 5년 차 개발자입니다.

최근에는 FastAPI · LangChain · LangGraph를 활용한 AI Agent 개발에 집중하며, 실제 서비스 환경에서 안정적으로 운영 가능한 AI 시스템 구축 경험을 쌓아가고 있습니다.

특히 할루시네이션 최소화를 위한 RAG 기반 Multi-Agent 시스템 구축 과정에서, 비정형 데이터에는 PGVector 기반 RAG를 적용하고 정형 데이터는 임베딩 가능한 구조로 가공하여 Agent 컨텍스트로 활용하는 하이브리드 검색 파이프라인을 직접 설계했습니다. 또한 Ask-back 로직과 Redis 기반 대화 메모리를 결합해 멀티턴 대화 품질과 응답 정확도를 향상시켰습니다.

"아는 만큼 보이고, 보이는 만큼 더 좋은 시스템을 만들 수 있다"는 신념으로, IT 뉴스와 개발자 커뮤니티를 통해 최신 기술 동향을 꾸준히 학습하며 개발 역량을 지속적으로 확장해나가고 있습니다.

학력한양대학교 공학대학원 컴퓨터공학과 재학 중 GPA 4.5 이전 직장㈜에이다루트 AX팀 대리 (2021.05 – 2026.01) 자격증정보처리기사 · 컴퓨터활용능력 2급 수상2022년 에이다루트 우수사원 병역군필 (공군 병장, 2018.10 – 2020.08)

04 · core values

핵심 가치관

개발자로서 일하는 방식, 그리고 좋은 시스템을 만들기 위해 지키는 세 가지 원칙

01
바이브 코딩 시대, 검증할 수 있는 개발자
AI 기반 바이브 코딩으로 코드 생산량이 눈에 띄게 늘어났지만, 그 코드를 제대로 이해하고 검증해낼 수 있는 개발자 능력이 더욱 중요해졌습니다. AI Times, 개발자 커뮤니티 등을 통해 꾸준히 최신 정보를 수집하고, 인프런과 같은 온라인 학습 플랫폼을 통해 개발 역량을 지속적으로 향상시키고 있습니다.
Continuous Learning · Verification Ability
02
DX 실현을 넘어 AX 실현
디지털 전환(DX)을 넘어 AI 전환(AX)을 실현할 수 있는 능력이 필요한 시대입니다. 단순히 AI 도구를 활용하는 것에 그치지 않고, 기업의 핵심 비즈니스 프로세스를 AI Agent로 자동화하고 최적화하는 실질적인 AX를 구현하는 엔지니어를 지향합니다.
AX Implementation · AI Transformation
03
전체 흐름을 설계하는 올라운더
백엔드 개발, AI Agent 설계, 배포 자동화 환경 구축까지 — 단일 레이어에 머물지 않고 시스템 전체 흐름을 이해하고 실행할 수 있는 올라운더가 되기 위해 꾸준히 노력하고 있습니다. LangGraph Agent 설계부터 Airflow 파이프라인, Docker CI/CD 구성까지 직접 수행해 온 경험이 이 방향을 뒷받침합니다.
Full-Stack Perspective · All-Rounder
05 · current focus

AI Agent 관심사

현재 깊이 탐구하고 있는 AI Agent 아키텍처와 기술 영역

⟳
Multi-Agent Orchestration
LangGraph 기반 멀티 에이전트 워크플로우. Router Agent → Sub-Agent 패턴으로 복잡한 질의를 분해하고 병렬 처리하는 아키텍처 설계.
LangGraph · LangChain · OpenAI
◈
Hybrid RAG 검색 시스템
BM25 + Dense Vector 검색 + RRF 결합. 비정형/정형 데이터를 아우르는 하이브리드 파이프라인과 Ask-back 로직을 통한 할루시네이션 방지 연구.
PGVector · FAISS · BGE-M3 · Redis
⌬
Data Pipeline × Agent
Airflow ETL로 수집된 정형 데이터를 Parquet/DuckDB로 적재하고 AI Agent가 SQL 로직으로 직접 조회하는 구조. 비용 효율적 컨텍스트 주입 방식 탐구.
Airflow · Parquet · DuckDB · FastAPI
▤
Agent Builder & LLMOps
Dify·Flowise를 활용한 노코드/로우코드 Agent 구성으로 PoC 속도 극대화. Langfuse 기반 Observability와 트레이싱으로 프로덕션 품질 확보.
Dify · Flowise · Langfuse · Docker
◎
CRAG & Agentic Search
Corrective RAG 아키텍처 기반 검색 결과 자기 수정 로직. 검색 신뢰도 평가 → 재검색 → 웹 폴백 흐름을 LangGraph 노드로 구현하는 패턴 연구.
CRAG · LangGraph · pg_bigm
🎓
머신러닝 모델 이해
한양대 대학원 수업과 개인 학습을 병행하며 다양한 ML 모델의 구조와 학습 방법론을 체계적으로 탐구하고 있습니다. 모델에 대한 깊은 이해를 바탕으로 AI Agent 설계에 적용하는 것을 목표로 합니다.
Scikit-learn · PyTorch · 한양대 대학원
